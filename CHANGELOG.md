# Release history

## 1.2.1

- Made the Upcoming events list scroll within its card and removed its 12-entry limit.

## 1.2.0

- Redesigned trip creation and editing, with optional settings tucked away.
- Added shortcuts to start a new itinerary, transfer, booking or checklist.
- Separated the trip destination from departure points on routes.
- Added mobile and bilingual regression coverage for the trip editor.

## 1.1.0

- Expanded Portuguese and English coverage across navigation, travel forms,
  reservations, validation, flight research, globe accessibility and PDF guides.
- Added a shared static-copy translation catalogue.
- Default example records translate while unchanged; user-written text is kept.
- Added browser checks for both languages and English PDF output.
- Required bilingual UI in the project's development instructions.

## 1.0.0

- Established official version numbering.
- Unified finance filters and refined the mobile green glass navigation dock.
